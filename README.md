# Scientific Calculator toolkit

## Overview
This project is a Python-based scientific calculator designed to perform both basic arithmetic and advanced mathematical computations.

## Motivation
Scientific calculators are essential tools in mathematics, engineering, and science education. This project demonstrates the implementation of mathematical computation using Python.

## Features

### Basic Operations
- Addition
- Subtraction
- Multiplication
- Division

### Advanced Operations
- Exponentiation
- Square Root
- Factorial

### Trigonometric Functions
- Sine
- Cosine
- Tangent

### Logarithmic Functions
- Base-10 Logarithm
- Natural Logarithm

### Reliability Features
- Input validation
- Error handling
- Division-by-zero protection

## Technologies Used
- Python
- Math Module
